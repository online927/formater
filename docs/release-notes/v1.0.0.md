First release of **Formater**: a Windows app that turns pasted text into the T.SAIFUDDIN & CO
*Quotation/Proforma* PDF.

## Download

Download **Formater.exe** below and run it. It is a single file and needs no installation: no .NET and no
Python, just Windows 10/11 with Microsoft Edge WebView2, which Windows already includes. The first time, Windows
SmartScreen may say the publisher is unknown. Click **More info → Run anyway**.

## What it does

- Paste text like this, then click **Export PDF** (Ctrl+E):
  ```
  Company: BuyersHub
  Ref: 100186
  Vernier Hook Depth Gauge, 10%, 5, 12011
  ```
- Address, GSTIN, phone, e-mail, Other Ref, Terms, Terms & Conditions and sign-off are optional lines. Click
  **Text format** in the app for the full list.
- **GST is automatic:**
  - A buyer GSTIN starting with 29, or a Karnataka address, gives CGST 9% + SGST 9%.
  - Anything else gives IGST 18%.
  - Override with `GST: IGST`, `GST: CGST+SGST`, `GST: 12%` or `GST: None`.
- **Discounts:** a **Disc %** column appears when any item has a discount, and Amount is after the discount.
- **Defaults:** today's date, Indian number format (1,23,456.00), and amounts worked out in exact decimals.
- **Live preview** of the page, plus a list of anything in the text that could not be read.
- **Long quotations:**
  - Long names and addresses wrap.
  - Crore-sized amounts move the columns so they don't overlap.
  - More items than fit continue onto further pages.
- **Settings** for the details that are the same on every quotation:
  - your address
  - the title
  - the buyer heading
  - the GST rate
  - the default unit
  - Terms, Terms & Conditions and sign-off
- **Command line:** `Formater.exe --export quotation.txt Quotation-100186.pdf` makes a PDF without opening a
  window.

## Layout

The PDF follows the handoff specification in `docs/handoff/SPEC.md`. Every build checks it against the reference
`Quotation-100186.pdf`:
- **Text:** every word is in the same place.
- **Pixels:** 0.11% differ at 150 dpi on Linux and 0.16% from the real exe on Windows.
- **Why any differ:** the logo lettering uses the outlined SVG instead of live Montserrat text, as SPEC.md asks.
